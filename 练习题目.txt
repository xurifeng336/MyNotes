练习 1：最基础

用户点击「登录」
→ 输入用户名和密码
→ 系统验证
→ 验证成功 → 进入首页
→ 验证失败 → 提示「用户名或密码错误」
→ 用户重新输入

练习 2：带判断

用户提交订单
→ 系统检查库存
→ 有库存 → 创建订单 → 支付
→ 无库存 → 提示库存不足 → 结束

支付阶段：

支付成功 → 订单状态改为「已支付」→ 发货
支付失败 → 订单状态改为「待支付」→ 提示用户重新支付


练习 3：带循环

程序启动
→ 读取任务列表
→ 判断是否还有未处理任务

如果有：
→ 取出一个任务
→ 执行任务
→ 判断执行是否成功
→ 成功 → 标记任务完成
→ 失败 → 记录错误
→ 回到「判断是否还有未处理任务」

如果没有：
→ 输出「全部任务处理完成」
→ 程序结束



练习 4：稍微复杂一点

用户上传视频
→ 检查文件格式

格式不支持：
→ 提示「不支持该格式」→ 结束

格式支持：
→ 开始转码
→ 判断转码是否成功

成功：
→ 提取音频
→ 上传视频和音频
→ 判断上传是否成功
→ 成功 → 返回文件链接
→ 失败 → 切换备用服务器 → 重新上传

转码失败：
→ 记录错误日志
→ 返回「处理失败」



练习 5：挑战一下 😏

交易系统每 5 分钟扫描一次市场
→ 获取符合条件的交易机会
→ 判断当前是否触发熔断

已熔断：
→ 跳过本轮交易
→ 等待下一轮扫描

未熔断：
→ 遍历交易机会
→ 判断当前持仓风险是否超过上限

超过：
→ 跳过该机会

未超过：
→ 计算交易风险
→ 判断风险是否合格

不合格：
→ 跳过

合格：
→ 创建挂单
→ 等待成交

成交：
→ 设置止损
→ 设置追踪止损
→ 持仓管理
→ 止损/追踪止损触发 → 平仓 → 记录交易结果

然后回到：
→ 每 5 分钟扫描一次市场
